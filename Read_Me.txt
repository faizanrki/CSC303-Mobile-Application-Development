# Smart Campus Canteen Engine

Smart Campus Canteen Engine is a Dart console application created for the CSC303 Mobile Application Development lab assignment.

The project demonstrates Dart fundamentals including variables, data types, control flow, collections, functions, arrow functions, and object-oriented programming.

## Features

- Student profile management
- Active account validation
- Wallet balance checking
- Canteen menu using Map
- Order items using List
- Voucher codes using Set
- Hostelite discount
- Day scholar discount
- Loyalty points discount
- One-time voucher usage
- Itemized receipt
- Insufficient balance handling
- Timestamped transaction logging

## Project Files

- `main.dart` - Main program entry point
- `student.dart` - Student profile and wallet operations
- `canteen_menu.dart` - Canteen menu and prices
- `order.dart` - Order item management
- `voucher_manager.dart` - Voucher validation and discounts
- `billing_engine.dart` - Billing, discounts, receipt and checkout
- `transaction_logger.dart` - Transaction logging using an arrow function
